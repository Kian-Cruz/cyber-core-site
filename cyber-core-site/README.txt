CYBER CORE // ORBITAL REACTOR PROTOCOL  (5 scenes)

Upload this folder's CONTENTS to your web host's public folder, keeping this structure:

  index.html
  lib/aframe.min.js
  models/spaceship.glb      <- your own model file (optional, a fallback ship is built in)

Then open your site address in the browser.
Test locally first:  python3 -m http.server 8000   then open http://localhost:8000
(Do not double-click index.html: browsers block loading the model from file://)
